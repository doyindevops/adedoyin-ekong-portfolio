All About Me

I'm a DevOps Engineer who loves building fast,secure, and scalable systems through automation. I design and implement CI/CD pipelines that accelerate software delivery while embedding security and compliance from the first line of code to production. My core stack is AWS, Azure and DigitaOcean, with working knowledge of GCP. I architect resilient cloud infrastructure-containerized on Kubernetes or serverless with Lambda and EventBridge-to ensure high availability,scalability, and performance. I care about tight feedback loops, clear observability, and reducing risk so teams can ship quickly without breaking things.

I also love documenting what I learn
Through real projects, and practical walkthroughs, I break down tools like GitHub Actions, Terraform, Kubernetes, and AWS into into step-by-step guides engineers can actually follow.
