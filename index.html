About Me

I'm a DevOps Engineer passionate about building fast, secure, and scalable systems through automation and a DevSecOps-first approach. I design and implement robust CI/CD pipelines that accelerate software delivery while embedding security and compliance from the first line of code to deployment in the cloud.
