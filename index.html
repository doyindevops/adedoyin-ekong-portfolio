About Me

I'm a DevOps Engineer passionate about building fast, secure, and scalable systems through automation and a DevSecOps-first approach. I design and implement robust CI/CD pipelines that accelerate software delivery while embedding security and compliance from the first line of code to deployment in the cloud. With deep expertise in AWS and DigitalOcean and working familiarity with Azure and GCP, I architect resilient cloud infrastructure—whether containerized or serverless, to ensure high availability, scalability, and performance. My work focuses on optimizing feedback loops, minimizing risk, and delivering value at speed without sacrificing stability. Driven by continuous improvement, I thrive on creating infrastructure that supports rapid innovation while keeping systems reliable, secure, and compliant.

I also love documenting my experiences and knowledge.
Through personal stories, real projects, and practical walkthroughs, I break down complex tools like GitHub Actions, Terraform, Kubernetes, and AWS into simple, relatable lessons.
