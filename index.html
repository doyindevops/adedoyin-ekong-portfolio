All About Me

I'm a DevOps Engineer who loves building fast,secure, and scalable systems through automation. I design and implement CI/CD pipelines that accelerate software delivery while embedding security and compliance from the first line of code to production. My core stack is AWS, Azure and DigitaOcean, with working knowledge of GCP.
